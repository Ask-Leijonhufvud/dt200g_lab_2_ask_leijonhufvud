# DT200G Laboration 2 - Analysera och optimera webbplats

[GitHub Pages]()

[Presentation]()

Detta var en universitetsuppgift med syftet att:
> * Kunna förstå och analysera webbplatsers uppbyggnad.
> * Förstå hur olika webbplatser fungerar på olika typer av enheter, som desktop, mobiltelefoner etc.
> * Kunna kritiskt granska webbplatser för se vad som fungerar bra och mindre bra.
> * Kunna se vilka bildformat som är lämpliga att använda, samt kunna optimera bilder för webb.
> * Kunna använda lämpliga tekniker för att infoga grafiskt material till webbsidor.
> * Träna på att skapa så kallade "screencasts", det vill säga att spela in det som händer på din skärm tillsammans med ljud från din mikrofon.
> * Kunna publicera videofilm till publiceringstjänst för video.

Uppgiften gick ut på att analysera och optimera webbplatsen som skapades i laboration 1.2 i kursen. Webbplatsen skulle analyseras med flera olika testverktyg. De förbättringar som föreslås och/eller är lämpliga skulle tillämpas på en kopia av webbplatsen och den och dess bildmaterial skulle sedan optimeras.
